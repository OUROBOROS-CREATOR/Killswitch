# KILLSWITCH

*Некоторые двери лучше не открывать. Некоторые игры — не начинать.*

Ты нашёл то, чего не должно было существовать.

Здесь нет правил. Нет гарантий. И, возможно, нет обратного пути.

Иногда экран моргает. Иногда что-то появляется там, где секунду назад ничего не было. А иногда игра знает немного больше, чем должна.

Говорят, некоторые вещи исчезают бесследно. Другие оставляют после себя пустоту.

**Не доверяй тишине. Не привыкай к темноте. И не пытайся вернуться туда, откуда тебя уже выпустили.**

*Ты уверен, что это просто игра?*

EN

# KILLSWITCH

*Some doors are better left unopened. Some games are better left unplayed.*

You have found something that was never meant to exist.

There are no rules. No guarantees. And perhaps, no way back.

Sometimes the screen flickers. Sometimes something appears where nothing existed just a second ago. And sometimes the game knows a little more than it should.

They say some things disappear without a trace. Others leave nothing but an empty space.

**Trust no silence. Get used to no darkness. And don't try to return to a place that has already let you go.**

*Are you sure this is just a game?*
